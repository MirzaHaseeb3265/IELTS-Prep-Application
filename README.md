# IELTS Academic Practice Lab

A beginner-friendly Streamlit MVP for independent IELTS-style practice.

## Current build
- Dashboard
- Reading mock with 3 original passages
- Automatic marking
- Practice band estimate
- Explanations after submission
- SQLite progress history
- Writing and Listening placeholders for the next phases

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Streamlit Community Cloud
Upload the whole folder to a GitHub repository. In Streamlit Community Cloud choose `app.py` as the main file.

## Important
This is an independent IELTS-style preparation tool. It is not affiliated with or endorsed by IELTS, Cambridge University Press & Assessment, British Council, or IDP. Scores are practice estimates only.
